## 🎬 Animações

### **Entrada de Elementos**
```
Landing Page:
  Logo     → Scale In (0.9 → 1.0)
  Título   → Fade In Up (delay: 0.1s)
  Texto    → Fade In Up (delay: 0.2s)
  Botões   → Fade In Up (delay: 0.3s)

Chat:
  Mensagens → Slide In (da esquerda/direita)
  Botões    → Fade In Up

Dashboard:
  Cards     → Scale In (sequencial)
  Tabela    → Fade In Up
```

### **Interações**
```
Hover Buttons   → Scale(1.05) + Shadow
Hover Cards     → Scale(1.02) + Border Glow
Click           → Scale(0.98) + Spring Back
Loading         → Pulse Animation
```
